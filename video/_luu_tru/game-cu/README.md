# Lưu trữ: video từ game cũ (đã bỏ 06/11/2026)

Bộ dựng F3 (từ vựng trên nền game, tv01–tv14) và F4 (3 giây trả lời, hn-*) quay màn hình game cũ `khachsan.html`.
Bảo đã có game mới "Khách sạn Vịnh Ā Bǎo", nên các video này **không đăng nữa**. Thay bằng F9 "Giáo trình 3D"
(`series/giaotrinh3d.mjs`, dữ liệu `giaotrinh/`).

Giữ lại để tham khảo cách làm (máy tự quay game bằng Playwright, chia câu hỏi thành video 3 câu).
Các tệp này dùng đường dẫn cũ (`video/tools/`, `video/config.json`), muốn chạy lại phải sửa đường dẫn.
